# Portfolio case study: dependency-aware charter workflow

Phase 7 converts a manually remembered charter checklist into a configurable workflow engine.

Engineering highlights:

- versioned templates instead of hard-coded task creation;
- transactionally generated booking work;
- idempotency and acyclic graph enforcement;
- automatic downstream blocking and unlocking;
- safe reopening with permanent reasons;
- deterministic date anchors and amendment synchronisation;
- role-controlled template editing;
- 235 database security and behaviour assertions across the project;
- live task dashboard and responsive operational interfaces.

All fixtures are synthetic. No Torrance Yachts client identities, documents, private contacts, bank information, or live commercial terms are included.
