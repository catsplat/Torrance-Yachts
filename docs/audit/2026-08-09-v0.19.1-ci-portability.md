# v0.19.1 CI portability correction

The v0.19.0 local release gate passed, but GitHub's clean Linux run exposed two
environment assumptions: the production Compose file still required the retired
Gmail ingestion token, and the MFA setup test assumed its ignored output
directory already existed.

v0.19.1 removes the obsolete Compose/environment contract, creates the MFA
artifact directory before writing, waits deterministically for enrolment or
challenge state, and adds synthetic production-package validation to the local
fail-fast release command. The production image also pins the same npm version
as local development and CI. Browser acceptance retains private Storage so the
real quarantine path is tested, and the destructive status token now meets the
small-text contrast threshold found by the Linux accessibility run.

The release tag is permitted only after the revised clean local release command
and GitHub Quality workflow both pass on the correction commit.
