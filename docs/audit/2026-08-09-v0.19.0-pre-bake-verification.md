## Release command

`npm run release:verify` reproduces these gates in order from a clean checkout,
stops at the first failure and writes the sanitized result to
`.artifacts/release-verification.json`. The `v0.19.0` tag may be created only if
that command succeeds against the tagged commit.

## Scope boundary

client, provider, macOS-user or live-data acceptance. Those remain deployment
and client-owned gates in the launch register.
