# v0.18.0 browser acceptance evidence

**Date:** 9 August 2026

## Scope

- unauthenticated redirect and generic invalid-login response;
- approved internal administrator sign-in;
- Inbox, Enquiries, Bookings, Tasks, and Settings in Chromium, Firefox, and
  WebKit;
- serious/critical automated WCAG A/AA violations on those routes;
- notification-centre navigation and dark-mode control;
- synthetic new-enquiry, follow-up, internal, circular, and unknown routes;
- run-scoped rehearsal reset.

## Result

The final local Playwright run completed 13 of 13 scenarios successfully in
49.2 seconds using one worker. All automatically detectable serious and critical
violations in the covered core pages were resolved. The rehearsal created no
external delivery and removed its operational records through the normal
administrator reset boundary.

## Local release gates

- ESLint: passed.
- strict TypeScript: passed.
- Vitest: 125 passed, 3 explicitly skipped local-provider integration checks.
- PostgreSQL pgTAP: 798 passed.
- PostgreSQL schema lint: no warnings.
- Next.js production build: passed for all 53 application routes.
- production dependency audit: zero known vulnerabilities.
- automation definitions: six inactive, credential-free workflows validated.
- production preflight and rendered Compose configuration: passed with synthetic
  values and no secret output.

The GitHub Linux clean-install and disposable browser job remain the publication
gate for the release branch.
