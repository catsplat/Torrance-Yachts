# v0.13 workflow and personal-alert verification

**Status:** Local verification passed; clean CI and client activation pending

## Acceptance targets

- Each active staff account controls its own email, phone, Telegram chat ID,
  channels, topics, and AI-summary preference.
- Gmail OAuth secrets are encrypted in Vault and not readable through normal
  application queries.
- The notification bell opens a personal notification centre with unread state.
- Global search returns authorised enquiries, bookings, tasks, yachts, contacts,
  and emails.
- Dark mode persists and does not alter workflow behaviour.
- Navigation and dashboard follow Inbox -> Enquiry -> Offer -> Booking ->
  Operations -> Follow-up.
- Automatic AI email analysis remains advisory and bounded.
- Internal alerts can be sent automatically; external Gmail work is draft-only
  and approval-controlled.
- Numbered tasks expose the required KYC, captain, invoice, and follow-up actions.
- All original tests, migrations, deployment checks, and security gates remain
  green.
